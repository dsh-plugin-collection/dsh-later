# dsh-later 宣传视频：创作 brief

一条 42.6 秒、1920×1080、30fps、无旁白的演示片。界面部分全部来自真机截图，不是复刻的 DOM。

## 目标

看片的人应该记住三件事，顺序就是片子的顺序：

1. 可以是一行命令（`/later +5s 检查部署结果`），不用开面板。
2. 到点它自己出现，气泡左边挂一支表，说明这条不是现在发的。
3. 关掉网页也照样触发，因为计时在服务端。

## 受众

已经在用 DSH 的人，以及决定要不要装这个插件的插件用户。他们认得「输入框」「会话」「dock」这些词，不需要解释 DSH 是什么。

## 素材怎么来的

界面镜头不是画出来的。`scripts/capture-real.mjs` 起一个只装本仓当前 `lib/` 的隔离 DSH 实例（`DSH_HOME` 指向临时目录），用 Playwright 真敲键盘、真按回车、真等倒计时、真 hover，逐帧截图 2 倍像素，侧栏再拍一遍 4 倍像素。产物在 `assets/real/`，每张图的裁切矩形、选择器、内核版本记录在 `assets/real/capture.json`。

| 镜头 | 素材 | 怎么来的 |
| --- | --- | --- |
| 打字 | `03-typing-01..06.png` | 分六段真键盘输入，每段截一张 |
| 倒计时 | `04-tick-01..04.png` | 回车后每秒一张，未经变速 |
| 到点气泡 | `bubble2.png`（裁自 `05-delivered.png`） | 等 `/later` 真的送达后截图 |
| 面板 | `02-panel.png` | 真点击「定时发送」按钮 |
| dock 四个动作 | `dock-row.png` | 同一张 dock 截图裁出整行 |
| 侧栏徽标 | `sidebar-row.png` | 从会话列表裁出的一行，2 倍像素，琥珀档 |

按钮位置不靠目测：采集脚本把 DOM 里按钮的矩形换算成相对图片的百分比写进 `capture.json`，片子在 HTML 里读这些百分比摆标线。

## 不做什么

- 不配音、不配字幕轨。片子在 README 里静音自动播放，屏幕文字就是全部文案。
- 不演示没做完的能力：没有日历式重复（每天九点那种归内核官方 `schedule_create`）。
- 不吹没有出处的数字。全片只有产品本身的行为。

## 交付物

- `renders/dsh-later-promo.mp4`：1080p 主片。
- `renders/dsh-later-promo-720p.mp4`：README 用的轻量版。
- `renders/poster.jpg`：末屏品牌卡，作视频封面。

## 判据

- 每一屏的字在 1080p 下不用暂停就能读完。
- `scripts/hf.sh lint` 零错误。
- 屏幕上出现的每一块界面，都能在 `assets/real/` 里找到对应的原图与采集记录。
