# 屏幕文案

全片没有配音，也没有旁白字幕轨。下面每一行都是画面上的字，与 `compositions/*.html` 逐字一致；界面截图里的字属于产品本身，不在此列。

句式取舍：一行说一件事，超过 14 个汉字的句子拆成两行；术语用产品自己的词（定时提醒、dock、服务端），不改写成「闹钟」「待办」。

## 第 1 场（0.0 至 6.0）

```
DSH · SESSION SCHEDULER

有些话，
不必现在说。

在输入框里说明什么时候发，剩下的交给服务端。

（真机截图）输入框：/later +5s 检查部署结果
按 回车，这条就开始计时

REAL GUI · DSH 0.2.1-rc.4 · dsh-later 1.10.0
```

## 第 4 场（14.5 至 18.5）

```
SYNTAX

什么时候，一句话说清

相对时长、挂钟时刻、重复序列。写不出来的时间，它才不猜。

相对时长    /later +5s 检查部署      → 5 秒后送达
挂钟时刻    /later 明天9点 交周报     → 明早 09:00 送达
重复序列    /later +1h*3 起来喝水     → 每小时一次，共 3 次

一次最多 10 条 · 多次写法的间隔不低于 60 秒
```

## 为什么不做配音

1. README 里的视频默认静音自动播放，配音加字幕轨等于两份文案要同步维护。
2. 画面的信息量已经够密，再叠人声会和字幕抢注意力。
3. 这个插件没有声音相关的功能可展示，音效只能是装饰。

要加背景音乐时，用 `hyperframes render -a <音频文件>` 或在 `index.html` 里放一条 `<audio>` 轨，音量建议 `data-volume="0.25"` 以下。
