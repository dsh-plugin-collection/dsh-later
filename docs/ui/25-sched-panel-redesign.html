1「工作时间」芯片到底定了什么（实测，不是猜）

把时间轴拖到下面几个点，看左栏「工作时间」的落点。规则来自 src/smart-window.ts:244-274。

2需要你拍板的两处

A. 午休段语义。现状 nextSmartTarget 在 12:00–14:00 返回 now + 2min——一个叫「工作时间」的芯片意味着「两分钟后」。 demo 里我改成「午休后 14:00」。这会改宿主侧共享函数的行为（/later 智能 命令与 dock 都吃它），不是纯 UI 改动，所以标出来请你确认。
B. 相对时长改为「选中即钉住」。现状提交 after_seconds，目标时刻 = 按下发送按钮那一刻 + 600s，所以面板开着打字时显示的绝对时刻每秒前滑。 demo 改成点芯片时钉住目标瞬间；提交时仍换算成 after_seconds = (钉住值 − 按下时刻)， 这样既让「看到的就是发送的」，又保住 dock 的暂停能力（pauseUnsupportedKind：只有 after 类可暂停）——不能图省事直接改发 at。
