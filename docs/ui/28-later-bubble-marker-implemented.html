结构与尺寸

宿主只把 key 为 user / steering 的节点交给我们的组件；气泡内容仍然来自官方工厂， 所以下面这段树里只有带 ss- 的三个节点是本插件新增的。 

// 宿主
<div data-chat-flow-kind="user">
  <div data-slot="conversation.chat.node">
    <div class="ss-row">              // 复刻 userRow：列向、右对齐、gap 6px
      <div class="ss-main">          // 仅 left / hover：行向、gap 8px
        <span class="ss-mark" />     // 16px 描边钟，margin-top 13px
        <!-- 官方 factory：conversation.chat.user.content -->
        <div class="…_userStack"> 气泡 / 图片行 / 引用摘要 </div>
      </div>
      <div class="ss-actions">       // 复刻：时间 13/24 + 复制 28×28
        <span class="ss-time" />
        <button class="ss-copy" />
      </div>
    </div>
  </div>
</div>

meta 行12px / 16px行高 16，与气泡间隙 2px，总高度 +18px

关于颜色。定稿用 tertiary（安静、和正文不抢）；想要更醒目就把 color 换成琥珀 --dsw-static-amber-500，一行改动，不新增设置。预览第一版（docs/ui/27）里的四种图标形态， 定稿只取了「系统描边钟」这一种。
