新版时钟图标 · 三态预览

插件只有一个点阵时钟图标（CLOCK_SVG），通过 CSS 颜色区分三种状态。 新版统一采用官方描边语言，三态仅颜色不同，几何与动画完全一致。

1. 侧栏实景 · 三态

三种 badge 状态在会话行中的表现
定时提醒会话 刚刚 scheduled
紧急提醒会话（2 分钟后触发） 刚刚 urgent
到期提醒会话（等待发送） 5 分钟前 overdue
三态仅颜色不同：
• scheduled → 定时紫 #8b5cf6（正常排期，无紧迫性）
• urgent → 警告琥珀 #f59e0b（≤5min 即将触发）
• overdue → 错误红 #f25a5a（已到期，等待会话空闲发送）
