时钟图标新旧对比

点阵时钟 badge 需要匹配 DSH 0.2.0 的现代设计语言。以下是三个新版方案供选择。

旧版（DSH 0.1.x）· 点阵时钟

像素风格 legacy
定时提醒会话 刚刚
10×10 点阵
特点：8 个 2×2 方块组成时钟外圈 + 2 个方块组成指针。
shape-rendering="crispEdges" 确保像素边缘锐利。
与 DSH 0.1.x 的点状状态图标风格呼应。

新版方案（DSH 0.2.0+）

方案 A · 平滑圆形时钟 A
定时提醒会话 刚刚
方案 A
特点：圆形外圈 + 两根指针 + 中心点。
匹配 DSH 0.2.0 的 spinner 风格（圆形 + 描边）。
语义最清晰（一眼看出是时钟）。
方案 B · 简约指针 B
定时提醒会话 刚刚
方案 B
特点：无外圈，仅指针 + 中心点。
最简洁，视觉干扰最小。
但可能不够直观（像十字而非时钟）。
方案 C · 圆点时钟（匹配状态点风格）C
定时提醒会话 刚刚
方案 C
特点：用圆点代替方块，保持点阵布局但更圆润。
与 DSH 0.2.0 的状态点风格（圆形）呼应。
是旧版点阵时钟的"平滑化"版本，语义过渡最自然。
