点阵时钟 → 官方风格重设计

原则：表现层（尺寸体系、描边、圆头线帽）采用 DSH 0.2.0 官方语言； 语义层（表盘 / 指针 / 呼吸 / 定时紫）逐一还原旧版点阵时钟。

1. 官方设计语言（实测源码）

DSH 0.2.0 spinner — 新图标必须遵循的词汇表
维度官方取值出处
viewBox 0 0 24 24，渲染尺寸由容器传入（侧栏 slot 为 14px） JSX: viewBox:"0 0 24 24", width:a, height:a
几何 <circle cx=12 cy=12 r=9.5>（24 体系下半径 9.5） JSX: spinnerTrack / spinnerArc
描边 fill:none; stroke:currentColor; stroke-width:2; stroke-linecap:round ._spinnerArc_1i3xo_48
轨道 track 与 arc 同几何，track 为弱化透明度 ._spinner_1i3xo_37 color: --dsw-alias-label-tertiary
动画挂载 动画类挂在 <g> 上（motion），不在 circle 上 JSX: <g class="spinnerMotion">
结论：新时钟不能再用 10×10 + fill 方块 + crispEdges（旧官方词汇）， 必须换用 24×24 + stroke 圆头线帽（现官方词汇）。

2. 旧 → 新语义映射（一一对应）

旧版元素（点阵时钟） 新版元素（官方风格） 共同语义
8 × 2px 方块组成外圈
<rect> × 8		 → 描边圆环
<circle r=9.5 stroke-width=2>		 表盘 — 离散点环 → 连续环（官方 track 同款几何）
2 × 2px 方块组成指针
<rect> × 2（12 点方向 + 3 点方向）		 → 两根圆头线段
<line stroke-linecap=round>		 时针 + 分针 — 同样指向 12 点与 3 点（= 3:00，定时→"到点"）
呼吸动画挂外圈
opacity .65 ↔ 1, 2.4s		 → 呼吸动画挂表盘环
同 keyframes，同周期		 "活着的定时" — 会话里有等待中的提醒
指针不透明度 1（静止） → 分针 opacity .85、时针 1（轻微主次） 指针静止 — 提醒未触发；不旋转，与宿主 spinner（转）区分
颜色 #8b5cf6（定时紫） → 颜色 #8b5cf6 不变 定时专属色 — 与宿主状态色板（灰/白/琥珀/红）区分
crispEdges 锐利像素边 → stroke-linecap: round 圆头 表现词汇切换：像素时代 → 描边时代（官方既定方向）

3. 侧栏实景对比

旧版 · 点阵时钟 legacy
定时提醒会话（进行中） 刚刚
定时提醒会话（空闲） 2 分钟前
旧 badge 是 10×10 fill 方块体系，与官方新 spinner 的 stroke 圆环体系并存时明显两代感：一方锐利像素、一方平滑圆头。
新版 · 官方风格时钟 modern
定时提醒会话（进行中） 刚刚
定时提醒会话（空闲） 2 分钟前
新 badge 与宿主 spinner 同一几何基因： 同 viewBox 24、同 r=9.5、同 stroke-width 2、 同 round 线帽。区别仅在：spinner 的 arc 在转（进行中）， 时钟的指针静止 + 表盘呼吸（定时等待中）。

4. 放大 4× · 逐笔对应

旧 · 8 点外圈 + 2 点指针
新 · 描边表盘 + 圆头指针
参照 · 宿主 spinner（同一几何）
为什么指针取 12 点 + 3 点：旧版点阵的两个方块就在 12 点方向 （rect x=4,y=2）和 3 点方向（rect x=6,y=4）， 即"3:00"——到点的时刻。新版线段端点严格换算： 12 点方向 (12,6.5)（r=5.5 长时针）、3 点方向 (17,12)（短分针）， 与旧版语义完全一致。

5. 新版交付源码（可直接进 session-presence.ts）

CLOCK_SVG（modern）
/**
 * 侧栏定时徽标 —— DSH 0.2.0 官方描边语言版点阵时钟。
 *
 * 语义还原（旧点阵 → 新描边）：
 *   8 点外圈  → circle r=9.5 stroke-width=2（= 官方 spinnerTrack 几何）
 *   2 点指针  → line ×2, stroke-linecap:round（= 官方 spinnerArc 线帽）
 *                12 点 (12,6.5) 时针 / 3 点 (17,12) 分针 —— 即旧版"3:00"
 *   呼吸动画  → 保留 .ring 呼吸 keyframes（挂表盘环）
 *   定时紫    → currentColor 由 .ss-presence 提供 #8b5cf6
 *
 * 表现还原（官方词汇）：
 *   viewBox 0 0 24 24 / 渲染 14px（= 宿主 spinner slot 尺寸）
 *   fill:none + stroke / stroke-linecap:round —— 摒弃 crispEdges
 */
export const CLOCK_SVG = `
<svg viewBox="0 0 24 24" width="14" height="14"
     fill="none" stroke="currentColor"
     stroke-width="2" stroke-linecap="round" aria-hidden="true">
  <circle class="ss-clock-face" cx="12" cy="12" r="9.5"/>
  <g class="ss-clock-hands">
    <line x1="12" y1="12" x2="12" y2="6.5"/>
    <line x1="12" y1="12" x2="17" y2="12" opacity="0.85"/>
  </g>
</svg>`;

/* styles.ts 配套 */
.ss-clock-face {
  animation: ss-clock-breathe 2.4s ease-in-out infinite;
}
@keyframes ss-clock-breathe {
  0%, 100% { opacity: .65; }
  50%      { opacity: 1;   }
}
.ss-clock-hands { opacity: 1; } /* 指针静止：提醒未触发，与宿主旋转 spinner 区分 */
与旧版共存：KERNEL_GENERATIONS 已有版本判定， 0.1.x 代次继续注入旧点阵 SVG，0.2.0+ 注入本 SVG —— 两套常量并排放置，检测逻辑复用既有的代次选择器，不新增探测机制。
